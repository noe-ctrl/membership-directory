# 事業計画数値「③減価償却費」の整合修正手順

## 不備の内容

「直近の決算年月」における申請システム入力値「③減価償却費」と、提出した損益計算書（決算書）の「減価償却費」が一致しない。**決算書に沿って入力し直し、根拠となる決算書類を再提出**する。

## 不一致が起きる典型的な原因

| 原因 | 対処 |
|---|---|
| 千円単位に丸めて入力した（例: 1,234,567円 → 1,234千円） | **1円単位で入力**する。切り捨て・四捨五入をしない。 |
| 販管費の減価償却費しか入力しておらず、製造原価報告書の減価償却費を含めていない | 製造原価報告書の減価償却費を **加算** する（手引きの定義に従う）。 |
| 逆に、製造原価分を含めて入力したが、損益計算書上の科目と突合できない資料を出していない | 製造原価報告書・販管費明細・個別注記表を **併せて提出** し、どの科目を合計したか明示する。 |
| 別の決算期の数値を入力した | 「直近の決算年月」と決算書の事業年度を一致させる。 |
| 決算書の科目名が「減価償却費」以外（例: 「償却費」「無形固定資産償却」「リース資産減価償却費」） | 手引きの「③減価償却費」の定義に該当する科目を確認し、該当するものだけを合算する。**該当科目にマーカーを引き、補記する。** |

## 作業手順

### 1. 決算書を揃える

「直近の決算年月」の事業年度の以下の書類（PDF）を用意する。

- 損益計算書（必須・再提出）
- 製造原価報告書（従来から作成している場合）
- 販売費及び一般管理費明細（従来から作成している場合）
- 個別注記表（従来から作成している場合）

> 不備通知の注意点2: 「※従来から作成している場合のみ※」。作成していない書類を新たに作る必要はないが、作成しているのに出していない場合は不備になる。

### 2. 突合表に転記する

`減価償却費_突合表.xlsx` の「突合表」シートに、決算書の科目ごとの金額を **1円単位** で入力する（青字セル＝入力欄）。

- 損益計算書の販管費に減価償却費が直接載っている場合はその金額
- 販管費明細に載っている場合はその金額（損益計算書の販管費合計の内訳であることを確認）
- 製造原価報告書の経費に減価償却費がある場合はその金額
- 個別注記表に減価償却累計額の注記しかない場合、それは「費用」ではないので合算しない（参考欄に記載のみ）

突合表の「合計（申請システムに入力する値）」と「現在の入力値」の差額が 0 になるまで確認する。

### 3. 申請システムの入力値を修正する

申請システムの「事業計画数値（労働生産性の計画値）」→「直近の決算年月」→「③減価償却費」に、突合表の **合計を1円単位で** 入力する。

- 「直近の決算年月」の年月が決算書の事業年度末と一致していることも確認する。
- ③減価償却費を修正すると労働生産性（付加価値額）の計算値が変わる。基準年・計画年の値と整合が崩れていないか、画面上の自動計算結果を確認する。

### 4. 決算書にマーカー・補記を入れる

不備通知の注意点3: **「補記、マーカー等で『③減価償却費』に該当する科目を明確にしてください」**

1. 損益計算書・製造原価報告書・販管費明細の「減価償却費」該当行に **黄色マーカー** を引く（PDF編集ソフトの蛍光ペン機能、または印刷→マーカー→再スキャン）。
2. 各マーカー箇所の余白に **「③減価償却費 ○○円」** と補記する。
3. 複数科目を合算している場合は、損益計算書の1ページ目の余白に合算式を補記する。
   例: `③減価償却費 = 販管費 減価償却費 1,234,567円 ＋ 製造原価 減価償却費 890,123円 = 2,124,690円`
4. マーカー後の金額が突合表の合計と一致していることを再確認する。

### 5. 1つのPDFにまとめて差し替える

不備通知の注意点2: **「再提出時は追加資料のみではなく、損益計算書（決算書）ももう一度ご提出ください。（損益計算書＋追加資料）」**

- 結合順: 損益計算書 → 製造原価報告書 → 販管費明細 → 個別注記表
- ファイル名: `提出版_損益計算書＋追加資料_マーカー済.pdf` として本フォルダに保存する。
- 申請システムの決算書添付欄で旧ファイルを **差替え** する。添付場所（欄）を間違えない。

## 確認事項

- [ ] 入力値が1円単位（末尾が000で切れていない、または決算書もそうであることを確認済み）
- [ ] 突合表の差額が 0
- [ ] 「直近の決算年月」と決算書の事業年度が一致
- [ ] 減価償却費に該当する科目すべてにマーカー・補記がある
- [ ] 損益計算書を含めた1つのPDFで再添付した
- [ ] 従来から作成している追加資料（製造原価報告書・販管費明細・個別注記表）を漏れなく含めた
