## 提出物の置き場所（運用ルール）

再申請で添付する最終版のPDFは、このフォルダ内の各サブフォルダに **「提出版_」を先頭に付けた名前** で保存する。

- `01_履歴事項全部証明書/提出版_履歴事項全部証明書_YYYYMMDD発行.pdf`
- `02_減価償却費の整合/提出版_損益計算書＋追加資料_マーカー済.pdf`

Dropbox の元フォルダ（旧提出物）はそのまま残し、修正版は本フォルダに集約する。旧ファイルを上書きしない。

- 決算書の減価償却費は **22,704,796円**（販売費及び一般管理費明細）。申請側は 22,704,793円 で **3円** 不足していた。

- 事業計画書（その3）に貼付されたシステム画面の画像と算定根拠の数値が食い違っている（詳細は `02_減価償却費の整合/申請システム修正値と作業手順.md` の4）。再申請前に要確認。

## 対応の流れ（推奨順）

1. **今日中**に履歴事項全部証明書の交付請求を行う（オンライン請求なら翌営業日受取が可能。期限まで2日しかないため最優先）。
2. 決算書（損益計算書・製造原価報告書・販管費明細・個別注記表）を手元に揃え、`減価償却費_突合表.xlsx` に科目ごとの金額を1円単位で転記する。
3. 突合表の「合計」を申請システムの「③減価償却費（直近の決算年月）」に **1円単位で** 入力し直す。
4. 決算書PDFの該当科目にマーカー・補記を入れ、損益計算書＋追加資料を **1つのPDF** にまとめて再添付する。
5. `03_再申請前チェックリスト.md` を全項目確認し、再申請する。
