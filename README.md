# membership-directory

会員名鑑（マッチングシート）の Web アプリです。`index.html` を静的ホスティング（GitHub Pages など）で配信し、
会員データは Google Apps Script（GAS）の Web アプリから取得します。

## 構成

| ファイル | 役割 |
| --- | --- |
| `index.html` | フロントエンド（ログイン・会員一覧・キーワードマッチング・AI社員チャット） |
| `gas/ai-employee.gs` | GAS 側の AI社員バックエンド（`doPost`）。既存の GAS プロジェクトに追加します |

## AI社員（AIコンシェルジュ）

ログイン後、画面右下の「🤖 AI社員に相談」から、会員名鑑をもとにした相談ができます。

- 「Web制作を頼める人を探して」など、条件に合う会員の紹介
- 相性の良さそうな会員同士の組み合わせ提案
- 紹介文・自己紹介文などの文案作成
- 回答内で紹介された会員はカードとして表示され、タップすると一覧をその会員だけに絞り込めます

AI には会員の氏名・会社名・仕事内容・会場・区分・探している方・内容のみを渡します。
メールアドレス・電話番号・LINE・Facebook・写真 URL は送信しません。

### セットアップ（管理者向け）

1. 会員データを返している既存の GAS プロジェクトを開き、新しいスクリプトファイルを追加して
   `gas/ai-employee.gs` の内容を貼り付けます。
2. 「プロジェクトの設定」→「スクリプト プロパティ」に以下を追加します。

   | プロパティ | 値 |
   | --- | --- |
   | `ANTHROPIC_API_KEY` | Anthropic の API キー（必須） |
   | `MEMBER_PASSWORD` | 会員名鑑のログインパスワード（既存の `doGet` で照合している値と同じもの） |
   | `AI_MODEL` | 省略可。既定は `claude-opus-5` |
   | `AI_EFFORT` | 省略可。`low` / `medium` / `high`。既定は `medium` |

3. 「デプロイ」→「デプロイを管理」→ 鉛筆アイコン →「新しいバージョン」で再デプロイします。
   （URL が変わらない「既存デプロイの更新」を選んでください。URL が変わった場合は `index.html` の `GAS_API_URL` を更新します）
4. サイトを開き、ログイン後に「🤖 AI社員に相談」から動作を確認します。

`ANTHROPIC_API_KEY` が未設定、または `doPost` が未デプロイの場合、チャット上に案内メッセージが表示されます。
既存の会員一覧機能には影響しません。

### 仕組み

- フロントエンドは `GAS_API_URL` に `{ action: "chat", password, members, messages }` を POST します
  （CORS プリフライトを避けるため `Content-Type` は指定せず、GAS 側で JSON として解釈します）。
- GAS は `MEMBER_PASSWORD` で認証後、Claude API（`/v1/messages`）を呼び出します。
  会員一覧はシステムプロンプトに含め、プロンプトキャッシュの境界を置いています。
- 回答は JSON スキーマ（`reply` と `recommended[]`）で構造化され、`recommended[].id` は
  会員一覧の並び順（`M1`, `M2`, …）に対応します。存在しない id は GAS 側で除外されます。
- 直近 12 メッセージのみを会話履歴として送信します。
