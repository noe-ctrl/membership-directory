# membership-directory

静的HTMLだけで動く小さなアプリ集です。ビルド不要で、GitHub Pages などにそのまま置けます。

| パス | アプリ | 説明 |
|---|---|---|
| `index.html` | 会員名鑑（マッチングシート） | Google Apps Script をバックエンドにした会員一覧・マッチング |
| `kakeibo/index.html` | 家計簿 | うきうき家計簿から移行できる、端末内保存型の家計簿アプリ |

## 家計簿（`kakeibo/`）

サーバー不要・スマホ対応の家計簿アプリです。データはブラウザの localStorage に保存されます。

### 主な機能

- **入力** … 支出/収入、日付、分類・項目（チップ選択＋自由入力）、金額、メモ、支払方法
- **一覧** … 月ごとの明細を日付別に表示、キーワード絞り込み、タップで編集・削除
- **カレンダー** … 日ごとの収入・支出をひと目で確認、日付をタップして明細表示・その日に入力
- **集計** … 月別の分類別内訳（ドーナツグラフ、項目ごとの内訳）、年間の月別収支グラフと表
- **予算** … 月の支出合計と分類ごとの予算、達成率バー、残り日数から1日あたりの目安を表示
- **レシート入力** … 1枚のレシートの品目をまとめて入力（合計金額との突き合わせ付き）。カメラ撮影・写真からの読み取りにも対応
- **口座・支払方法** … 現金・カード・銀行口座などの残高管理と、口座間の**振替**
- **定期的な収支** … 家賃・給与・積立振替など毎月決まった収支を自動入力
- **全期間検索** … 一覧の検索で「全期間」にチェックすると、月をまたいで検索
- **暗証番号ロック** … アプリを開いたとき／5分以上バックグラウンドにしたときに暗証番号を要求
- **設定** … 分類・項目・口座の管理、CSV取り込み、CSV/JSON書き出し、バックアップ復元
- ホーム画面に追加してオフラインでも利用できます（PWA）

### レシートの読み取り（OCR / AI）

「入力 → レシートをまとめて入力 → 📷 レシートを読み取る」で、レシートの写真から日付・店名・品目・金額を読み取って明細に入れます。読み取り方法は設定で切り替えられます。

| 方法 | 費用 | 精度 | 設定 |
|---|---|---|---|
| ブラウザ内OCR（初期設定） | 無料 | 中程度。明るい場所で平らに撮ると安定します。読み取り後は必ず内容を確認してください | 不要（初回に日本語辞書を自動ダウンロード） |
| AI読み取り | Anthropic API の従量課金（1枚あたり数円程度） | 高い。品目名の正規化と分類の推定まで行います | 下記の手順で GAS をデプロイ |

**AI読み取りのセットアップ**

1. [Google Apps Script](https://script.google.com) で新しいプロジェクトを作り、`kakeibo/gas/receipt-ai.gs` の内容を貼り付けます。
2. 「プロジェクトの設定 → スクリプト プロパティ」に `ANTHROPIC_API_KEY`（Anthropic のAPIキー）を追加します。
3. 「デプロイ → 新しいデプロイ → ウェブアプリ」で「次のユーザーとして実行: 自分」「アクセスできるユーザー: 全員」としてデプロイし、`…/exec` のURLを控えます。
4. 家計簿アプリの「設定 → レシート読み取りの設定」で「AI読み取り」を選び、URLを貼り付けます。

URLを知っている人は誰でもそのGASを呼び出せる（＝あなたのAPIキーで課金される）ため、URLは公開しないでください。

### うきうき家計簿からの移行手順

1. うきうき家計簿でデータを **CSV出力（エクスポート）** し、ファイルをスマホやPCに保存します。
2. 家計簿アプリの **設定 → うきうき家計簿から移行（CSV取り込み）** で「CSVファイルを選ぶ」を押し、そのファイルを選択します。
3. 文字コード（Shift_JIS / UTF-8）と列（日付・分類・項目・金額・メモ・収支）は自動判定されます。
   プレビューを確認し、必要なら「列の割り当て」を手動で直してください。
   - 「収支」列がない場合は、分類名から判定 / 収入列・支出列 / 金額の符号 などの判定方法を選べます。
4. 「◯件を取り込む」を押すと取り込み完了です。CSVに含まれる分類・項目は自動で登録されます。
   同じファイルを2回取り込んでも、登録済みと同じ内容の行は重複としてスキップされます。

「収支」列に「振替」があり「振替先」列がある場合は口座間の振替として取り込まれ、「口座」「支払方法」列に出てくる口座名は自動で口座に登録されます。

取り込みに対応しているCSVの例:

```
日付,収支,分類,項目,金額,メモ
2026/08/01,支出,食費,スーパー,"3,480",週末の買い物
2026/08/10,収入,給与,給料,280000,8月分
```

```
日付,カテゴリ,内容,収入,支出,備考
2026-09-03,給与,,280000,,
2026-09-04,食費,コンビニ,,560,
```

### Webアプリでできないこと

- ホーム画面ウィジェット、Googleドライブなどへの自動バックアップ（手動でJSONバックアップを保存してください）
- 暗証番号ロックは端末内のデータを暗号化するものではありません。端末自体の画面ロックと併用してください

### バックアップについて

データは端末のブラウザ内にのみ保存されます。機種変更やブラウザのデータ削除に備えて、
**設定 → JSONバックアップを保存** を定期的に行ってください。復元は「JSONバックアップを復元」から行えます。

### 公開方法

リポジトリをそのまま GitHub Pages で公開すると `https://<user>.github.io/<repo>/kakeibo/` でアクセスできます。
`kakeibo/index.html` をローカルで直接開いても動作します（Service Worker はHTTP(S)配信時のみ有効）。
