# membership-directory

守成クラブ ヒルノ渋谷会場 向けの静的Webアプリ集です。各ファイルは単体のHTMLとして動作します。

| ファイル | 内容 |
| --- | --- |
| `index.html` | マッチングシート（会員名簿の検索・マッチング。GAS連携） |
| `timekeeper-test.html` | タイムキーパー係マニュアルの効果測定テスト（12問・合格ライン80%） |

## timekeeper-test.html について

- 単一選択・複数選択・○×の3形式で出題し、1問ごとに正解と解説（マニュアルの該当セクション）を表示します。
- 結果画面でセクション別の正答数と振り返りを表示し、「結果をコピー」で代表への報告文をクリップボードに入れられます。
- 受験履歴は端末の `localStorage` に保存されます（最大20件）。
- 受験結果を集計したい場合は、ファイル内の `RESULT_POST_URL` に GAS などの受け口URLを設定してください（空欄なら送信しません）。
- 問題の追加・修正は `QUESTIONS` 配列を編集してください。
