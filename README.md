# membership-directory

静的HTMLだけで動く小さなアプリ集です。ビルド不要で、GitHub Pages などにそのまま置けます。

| パス | アプリ | 説明 |
|---|---|---|
| `index.html` | 会員名鑑（マッチングシート） | Google Apps Script をバックエンドにした会員一覧・マッチング |
| `kakeibo/index.html` | 家計簿 | うきうき家計簿から移行できる、端末内保存型の家計簿アプリ |

## 家計簿（`kakeibo/`）

サーバー不要・スマホ対応の家計簿アプリです。データはブラウザの localStorage に保存されます。

### 主な機能

- **入力** … 支出/収入、日付、分類・項目（チップ選択＋自由入力）、金額、メモ、支払方法
- **一覧** … 月ごとの明細を日付別に表示、キーワード絞り込み、タップで編集・削除
- **カレンダー** … 日ごとの収入・支出をひと目で確認、日付をタップして明細表示・その日に入力
- **集計** … 月別の分類別内訳（ドーナツグラフ、項目ごとの内訳）、年間の月別収支グラフと表
- **予算** … 月の支出合計と分類ごとの予算、達成率バー、残り日数から1日あたりの目安を表示
- **定期的な収支** … 家賃・給与など毎月決まった収支を自動入力
- **設定** … 分類・項目の追加/編集/並べ替え、CSV取り込み、CSV/JSON書き出し、バックアップ復元
- ホーム画面に追加してオフラインでも利用できます（PWA）

### うきうき家計簿からの移行手順

1. うきうき家計簿でデータを **CSV出力（エクスポート）** し、ファイルをスマホやPCに保存します。
2. 家計簿アプリの **設定 → うきうき家計簿から移行（CSV取り込み）** で「CSVファイルを選ぶ」を押し、そのファイルを選択します。
3. 文字コード（Shift_JIS / UTF-8）と列（日付・分類・項目・金額・メモ・収支）は自動判定されます。
   プレビューを確認し、必要なら「列の割り当て」を手動で直してください。
   - 「収支」列がない場合は、分類名から判定 / 収入列・支出列 / 金額の符号 などの判定方法を選べます。
4. 「◯件を取り込む」を押すと取り込み完了です。CSVに含まれる分類・項目は自動で登録されます。
   同じファイルを2回取り込んでも、登録済みと同じ内容の行は重複としてスキップされます。

取り込みに対応しているCSVの例:

```
日付,収支,分類,項目,金額,メモ
2026/08/01,支出,食費,スーパー,"3,480",週末の買い物
2026/08/10,収入,給与,給料,280000,8月分
```

```
日付,カテゴリ,内容,収入,支出,備考
2026-09-03,給与,,280000,,
2026-09-04,食費,コンビニ,,560,
```

### バックアップについて

データは端末のブラウザ内にのみ保存されます。機種変更やブラウザのデータ削除に備えて、
**設定 → JSONバックアップを保存** を定期的に行ってください。復元は「JSONバックアップを復元」から行えます。

### 公開方法

リポジトリをそのまま GitHub Pages で公開すると `https://<user>.github.io/<repo>/kakeibo/` でアクセスできます。
`kakeibo/index.html` をローカルで直接開いても動作します（Service Worker はHTTP(S)配信時のみ有効）。
